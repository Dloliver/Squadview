# SquadView Viewer UX Phase 1.3

Changes:

- Following Live cards now toggle between Add to view and Remove from view.
- A selected stream can be removed directly from Following Live without opening View List.
- YouTube Companion remains visible in desktop Grid + Chat.
- With YouTube + Grid + Chat the four positions are focused Twitch, YouTube, rotating Twitch, and Twitch chat.
- No Supabase migration is required.
- Twitch provider token refresh is intentionally not changed in this bundle; it needs a secure server-side refresh flow.
