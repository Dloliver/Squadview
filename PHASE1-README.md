# SquadView Monetization Phase 1

This bundle adds the monetization and Saved Squads foundation without changing the current eight stream viewer limit or automatic layout behavior.

## Included

- Server authoritative Free and Premium entitlements
- Stripe ready billing customer and subscription tables
- Normalized Saved Squads and Squad Members tables
- Database enforced Free and Premium limits
- Free: 3 Saved Squads, up to 8 creators each
- Premium architecture: unlimited Saved Squads, up to 16 creators each
- Saved Squads tab with live member status and one click launch
- Save current builder/view as a named Squad
- Account plan status
- Premium value preview
- Updated privacy and terms copy for Twitch account sync and Saved Squads

## Not included yet

- Stripe Checkout and webhooks
- Editing a Saved Squad beyond the current eight stream builder
- Live notifications
- YouTube Companion
- Multi Window and Second Screen
- Provider independent ad refactor

Run the SQL migration before testing Saved Squads.
